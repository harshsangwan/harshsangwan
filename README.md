## Selected projects

### 01 · Risk-Aware Deep Q-Learning for 2048

**Reinforcement learning · PyTorch · Sequential decision-making**

A collaborative project exploring decisions under stochastic tile generation. The implementation includes five DQN variants, risk-adjusted action selection, a separate MCTS player, seeded evaluation tools, and an interactive Pygame demo.

**Current focus:** substantive multi-seed experiments and ablations before drawing conclusions about playing strength.

[View the public repository →](https://github.com/RUDraksh12369/Risk-Aware-Deep-Q-Learning-Agent-for-Playing-2048-in-a-Stochastic-Environment)

### 02 · Autonomous Underwater Survey Vehicle

**AI planning · A* search · Energy-aware navigation · Simulation**

An underwater mission simulator that plans survey routes around terrain, currents, battery limits, and charging stations. It compares four A* heuristics and provides a desktop mission replay and evaluation workflow.

*Private repository · Project summary only*

### 03 · Autonomous Warehouse Delivery Agent

**Classical AI · Constraint satisfaction · Bayesian sensing · MDPs**

A delivery-agent simulation combining A* navigation, CSP task allocation, uncertain sensing, and a battery policy solved with value iteration. Controlled experiments examine the effects of planning, sensing reliability, and resource constraints.

*Private repository · Project summary only*

### 04 · AquaVision Desktop

**Computer vision · YOLO · ByteTrack · Offline desktop applications**

A native desktop workflow for aquatic image and video analysis, with tracking, optional species classification, relative size estimates, and dataset checks. The offline application is implemented; custom fish-model integration and Windows acceptance testing remain pending.

*Private repository · Project summary only*
